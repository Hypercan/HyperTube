# v1 tek kullanıcılı

HyperTube v1 yalnızca sahibinin kişisel aracıdır: hesap sistemi, çoklu kullanıcı veri modeli ve kullanıcı başına maliyet/kota yönetimi bilinçli olarak kapsam dışıdır. Bu, Gemini maliyetini ve YouTube API kotasını tek kişiye göre boyutlandırmayı ve ürünü hızlı denemeyi sağlar; kod çoklu kullanıcıya kapı kapatmamalı ama onun için tasarlanmamalıdır.
